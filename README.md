# WeLumen 使用说明

WeLumen 是一个桌面小助手：常驻一个可拖动的悬浮球，让电脑上的 AI 助手（Claude Desktop、Cursor 等支持 MCP 的工具）能够**只读**查看本机微信的会话、联系人、聊天记录，并能查看聊天中的图片、表情、收听语音、播放视频（视频为微信本地原始文件，不解密）。

> WeLumen 只能"看"，不能"发"——它不会替你发送任何微信消息，数据全部保存在本机，不会上传。

> **版本要求**：目前仅支持 **PC 微信 4.1.15.x 及以上版本**（微信主程序 `Weixin.exe`）。低于该版本的微信无法读取登录账号与聊天数据，升级微信后再使用。

## 快速开始（二步接入 AI）

> 首次使用，需要保持微信登录，后续数据库密钥、图片密钥、表情本地文件解密密钥，会持久化在本地，就不需要登录微信了

1. **启动 WeLumen**
   双击 WeLumen.exe，桌面出现悬浮球，MCP 服务会自动启动。
   
2. **让 AI 学会使用**
   点 **复制 AI 使用提示词** → 粘贴到 AI 工具的对话框发送。之后就可以直接用自然语言提问了，比如：
   - "帮我看看最近有哪些未读会话"
   - "获取和某某的聊天记录"
   - "把昨天那张图片解出来给我看"

## 悬浮球

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 移动位置（位置会自动记住） |
| 左键单击 | 打开配置窗 |
| 右键 | 菜单：打开配置 / 启停服务 / 复制配置 / 隐藏 / 退出 |
| 鼠标悬停 | 球体轻微放大 |

**图标含义**

- 右下角小圆点 = MCP 服务状态：<br>
  🟢 绿色 运行中 ｜ 🟡 黄色 启动/停止中 ｜ 🔴 红色 未启动或失败
- 右上角数字 = 当前登录微信的未读消息总数（超过 99 显示 99+，无未读时隐藏；公众号等官方账号不计入）

## 配置窗说明

- **服务状态**：显示 MCP 服务运行状态、地址与运行时长。
- **服务配置**：MCP 端口（默认 4588）、密钥（可显示/复制/重新生成）。一般保持默认即可。
- **接入 AI 客户端**：服务地址、鉴权请求头、**复制 MCP 配置**、**复制 AI 使用提示词**。
- **启动设置**：是否随 WeLumen 自动启动服务、是否开机自启。
- 底部：打开日志目录、退出 WeLumen。

## 托盘图标

关闭窗口后 WeLumen 仍在托盘运行。托盘图标右键可显示悬浮球、启停服务、打开配置、退出。

## 常见问题

**Q：AI 说连不上 / 工具列表是空的？**
① 确认悬浮球右上角是绿点（服务运行中）；② 确认已把"复制 MCP 配置"的内容粘贴进 AI 工具并重启了它；③ 若重新生成过密钥，需重新复制配置并更新 AI 工具。

**Q：AI 说"未找到该微信账号"？**
先打开配置窗确认服务已启动，然后在 AI 对话里发一次"复制 AI 使用提示词"里的内容（或直接说"调用 get_login_accounts 获取账号"），让 AI 重新获取账号列表。

**Q：换了端口或重新生成密钥后 AI 失效？**
重新点"复制 MCP 配置"，更新到 AI 工具的设置里。

**Q：悬浮球不见了？**
在托盘图标右键 → 显示悬浮球。

**Q：复制按钮点了没反应？**
剪贴板可能被其他程序（如输入法、剪贴板管理器）短暂占用，再点一次即可；连续失败请到日志目录查看原因。

**Q：卸载 / 退出后我的数据在哪？**
聊天记录始终在微信本机数据目录中，WeLumen 不复制、不上传；解密出来的图片/语音/表情缓存在程序目录的 `media_cache` 文件夹，可随时整个删除；视频直接使用微信本机原始文件，不做复制。
